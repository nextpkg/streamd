# Streamd 设计导读

Streamd 的核心是把一份输入媒体分发给多种消费者：协议处理、播放、录制各自有明确边界，慢客户端不应拖住整条流。服务负责转发与封装，不负责视频转码。

- [架构与数据流](architecture.md)：单机媒体管线、双节点回源、配置与录制边界。
- [内存设计](memory.md)：分块分配、载荷共享、GOP 与 HLS 生命周期。
- [关键设计取舍](design-decisions.md)：GC 压力、共享载荷、回源合并、关键帧切换、异步收尾和 HLS 退役宽限。
- [性能与复现](performance.md)：分配策略对照、1C2G 受限容量及稳定性结果。

图中的组件对应仓库代码，性能数据标明版本与负载；设计意图和测试结论分开描述。
